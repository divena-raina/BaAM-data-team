# BAaM — Behavioral Crime Pattern Modeling (Data & ML)

This repository contains the data and analytics foundation for an AI-driven
behavioral crime pattern modeling platform developed at the Behaviour Analytics
& Modelling (BAaM) Lab.

The project supports exploratory analysis, feature engineering, and data pipelines
used in predictive modeling workflows to help stakeholders identify patterns and
trends in large-scale crime data.

## Problem Context
Law enforcement and public-sector stakeholders often work with fragmented,
high-volume datasets that are difficult to transform into actionable insights.
This project focuses on structuring and preparing crime data to enable
AI/ML models that support predictive analysis and decision-making.

## What This Repository Includes
- Raw and cleaned datasets 
- Data preprocessing and feature engineering pipelines
- Jupyter Notebooks for data exploration, validation, and transformation
- Outputs supporting downstream ML modeling and evaluation
- Version-controlled workflows supporting multi-sprint delivery

## Tech Stack
- Python, Pandas, NumPy
- Jupyter Notebooks
- CSV-based datasets
- Git / GitHub for version control

## Notes
This repository focuses on the data and ML foundations of the platform.
Frontend visualization and application layers are maintained separately.
